How to use this page
  1. In Mentimeter, add a Select answer quiz slide for each question below.
  2. Click Copy next to the question and each answer, and paste them into Mentimeter. The copied text is plain (no backticks and no A/B/C/D letters). Tick the answer marked Correct.
  3. Quiz slides don't have much room for text, so add the code as an image: Copy image puts a PNG on the clipboard, Download PNG saves it. Put it on the quiz slide, or on the slide before it. The image uses the same colours as the page:
  4. Why is the explanation to show or say after the vote. Notes for the presenter are not for the slides.
